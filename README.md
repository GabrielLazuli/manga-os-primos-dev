# 📚 Mangá Beneficente - Os Primos Dev

Este é o repositório oficial da *landing page* criada para o lançamento do mangá independente do canal **Os Primos Dev**. O objetivo desta página é apresentar a história, destacar as artes do projeto e direcionar os leitores para a plataforma de compra, arrecadando fundos para a nossa causa.

## 🎨 Sobre o Projeto

Uma página única (*One-Page*) desenvolvida do zero para destacar o trabalho artístico e a narrativa. O design foi estruturado para que as ilustrações e os personagens do mangá falem por si, mantendo o foco na conversão e no apoio comunitário. 

* **Ilustrações e Arte:** O projeto visual e os desenhos da obra.
* **Desenvolvimento Web:** Estruturação semântica focada em uma navegação direta e rápida para o checkout.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível do conteúdo e da hierarquia de textos.
* **CSS3:** Estilização visual, manipulação do Box Model e formatação de botões de conversão.
* **Git e GitHub:** Versionamento de código e hospedagem através do GitHub Pages.

## 🚀 Estrutura da Página

1. **Vitrine Principal:** Apresentação visual de impacto com a capa do mangá.
2. **O Nosso Propósito:** Seção de transparência explicando a causa beneficente e o destino da arrecadação.
3. **Prévia da Obra:** Amostras das páginas finais para atestar a qualidade visual do projeto.
4. **Checkout:** Integração direta com plataforma segura de pagamentos.
